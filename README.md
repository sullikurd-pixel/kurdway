# KURDWAY
Free, independent hiking and navigation platform for Kurdish regions in Iran, Iraq, Türkiye and Syria.

Founder & Developer: Sulli Kurd

Planned languages: English, Sorani (RTL), Kurmanji. Mobile and web, offline maps, community trails and privacy by default.

Status: planning; no production application or verified routes yet.
