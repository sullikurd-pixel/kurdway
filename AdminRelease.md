# Admin analytics development release
Local owner-only console. Registration counts are drawn from the SQLite users table, including 7/30/90 day cohorts, verified accounts and plan distribution. User list is read-only and limited to latest 100. No real billing, traffic analytics, customer OTP, account blocking, MFA, audit log or production deployment yet. Do not infer revenue from premium flags. Tests are smoke tests only; run locally before relying on this update. The local password is separate from customer accounts. Keep server bound to loopback. Do not expose behind a proxy until production authentication and authorization are implemented.
